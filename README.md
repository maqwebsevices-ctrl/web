# MaQweb Services website

A responsive, SEO-friendly single-page business website written in plain **HTML, CSS and JavaScript**. No framework, build step or paid library is required.

## Preview

Open `index.html` in a browser or run a small web server in this folder (`python -m http.server 8000`). The site works on phones, tablets and desktops. The sample images and optional web fonts require an internet connection.

## Important before going live

1. **Enquiries are already configured:** Business email is `maqwebsevices@gmail.com`, and WhatsApp is **+91 74619 79033** (`917461979033` including India's +91 calling code). Visitors can tap direct contact links, or complete the form and select **Enquire by email** or **Enquire on WhatsApp**. The email/WhatsApp app opens with an editable enquiry; the visitor must still press **Send**. To receive form submissions automatically without relying on a visitor's app, add a server-side form endpoint or form service.
2. **Choose your actual prices and services:** The three package descriptions are examples. They show **Custom quote** because no actual rates were supplied. Adjust scope and copy to match your offerings. Avoid promising features that are not included in your services.
3. **Replace concept examples:** Portfolio cards are clearly marked *illustrative*, not real past clients. Replace them with genuine completed client work when you have permission.
4. **Replace sample imagery:** Photos reference `images.unsplash.com` over HTTPS. Use properly licensed imagery relevant to your brand or host your own compressed images for more predictable performance. Set `alt` text for each actual image. Browser mockup image uses a CSS background.
5. **Deployment & indexing:** Put the site on your web host; connect a domain and HTTPS. Add an absolute `canonical` URL and `og:url` only **after** the live domain is known. Create and submit a sitemap using that domain, verify the website with Google Search Console, and consider a relevant Google Business Profile. Review meta title, description, local targeting, accessibility and page content. Basic SEO setup does not guarantee Google search rankings.
6. **Legal and other business information:** The supplied MaQweb logo, email and WhatsApp details are now included. Add a privacy policy if collecting data through a back end. No invented customer reviews, projects or prices are shown.
